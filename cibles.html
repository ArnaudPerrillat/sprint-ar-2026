Générer la cible de mon affiche

Dépose le fichier final de ton affiche (tel qu'il sera imprimé) : tu vois comment le téléphone la reconnaîtra, puis tu récupères un dossier à mettre dans experience/target/. Tout se fait dans ton navigateur, rien n'est envoyé sur internet.

  3. 03Il les retrouve dans la caméraPlus il y en a, partout sur l'affiche, plus la détection est rapide.

Que faire du dossier téléchargé ?
  1. Dézippe le fichier téléchargé.
  2. Sur GitHub, dans ton dépôt, ouvre le dossier experience/target/, puis Add file › Upload files : glisse tous les fichiers du dossier dézippé, puis Commit changes. Les fichiers de même nom sont remplacés ; tu peux laisser les anciens fichiers de démo.
  3. Dans AI Studio, récupère les changements depuis GitHub (synchronisation), puis vérifie l'aperçu : c'est ton affiche qui doit apparaître.
  4. Projet à plusieurs affiches : colle aussi le bloc "targets" dans experience.json (ou demande à l'agent de le faire).

Ton affiche change ? Régénère la cible : une cible faite sur une autre version de l'affiche ne sera pas reconnue, ou le contenu sera décalé.

Améliorer la reconnaissance de mon affiche
  • Du détail partout : texte, contours, trames, textures. Une grande zone d'aplat (vue « Zones vides » en rouge) n'aide pas le téléphone.
  • Du contraste en gris : regarde la vue « Vision du téléphone ». Un rouge et un vert de même clarté deviennent le même gris : le motif disparaît.
  • Pas de motif répété à l'identique : le téléphone ne sait plus quel morceau il voit. Varie les formes.
  • Teste sur le tirage : l'encre, le papier et la lumière changent le contraste. Garde du temps pour un essai réel.
